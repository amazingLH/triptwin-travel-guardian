# 面板持续加载修复与验证

日期：2026-10-14。此前应用基线为 `a3c624e`，材料提交为 `8968ac7`。

## 问题与判断边界

作者反馈公网证据区和字段置信度出现持续加载。原版本所有事件均默认排队并使用覆盖整个输出组件的加载遮罩；解析、校验、历史自动保存及状态联动会产生连续请求，多个派生面板重复刷新。部分后续步骤使用 `.then()`，上游失败仍可能重置或保存旧状态。实时核验只在轮询外层计算等待时间，单轮分页、网络重试和产物下载可能进一步延长等待。

本地原版正常路径能跑通，未稳定复现截图中的同一次公网永久加载；不能仅凭截图断言唯一根因或把所有第三方网络问题归为同一个 bug。本次修复针对已确认的事件调度、遮罩范围和超时预算问题，并加入失败与慢网络回归。

## 修复

1. 本地渲染、图片预览与历史保存不再走队列 SSE，且不显示整块加载遮罩。置信度、空间天气证据和巡检结果不会因为其他步骤运行而被整块覆盖。
2. 需向用户报错的操作仍走队列，但只在当前操作的单一位置显示简洁进度。当前 Gradio 版本的直接 HTTP 错误会丢失弹窗元数据，不能为关闭排队而牺牲“请先构建 / 确认字段”等提示。
3. 上游成功才执行后续渲染、清空、保存。失败时不继续成功分支，不覆盖已保存的正确结果；允许用户手动重试，不自动重复收费操作。
4. 移除隐式 `State.change` 多路联动，显式返回浏览器历史镜像及补全 / 方案 / 编辑区状态。非队列回调不能依赖自动状态事件，否则可能出现历史未写回或派生控件未更新；手填预算等值随快照保留，不因自动保存重置。
5. 解析、方案生成和实时巡检等操作采用一次在途触发，避免同按钮连续点击重复提交。
6. 实时 Agent 的会话创建、分页、网络重试、轮询和产物下载共用 150 秒操作预算，单次 HTTP 超时也受剩余预算约束。超时失败不标记成功；中断请求有单独最多 5 秒的网络等待预算，不重新发送用户消息。网络库的分阶段超时不是精确到秒的硬实时保证，已发生费用不会因中断而退回。

## 验证

- 自动化回归：164 项测试通过，含加载范围、成功分支、显式历史镜像、补全值保留，以及分页 / 重试共用超时预算和超时中断。
- 离线评测：2 个案例通过；Ruff、Python 编译和 Git diff 检查通过。
- 本地 Edge 浏览器：桌面完整回归两轮、390px 手机宽度一轮。覆盖空行程 / 低置信错误提示，解析→风险→Plan B→应用，人工延迟巡检请求时其他面板仍可读，同按钮重复点击只提交一次，网络连接失败后重试，以及刷新恢复历史结果。
- 浏览器回归脚本：[check_loading_ui.cjs](../scripts/check_loading_ui.cjs)。需安装 Playwright 与 Edge；针对本地测试服务执行 `node scripts/check_loading_ui.cjs http://127.0.0.1:7860`，手机宽度加 `--mobile`。
- 浏览器验证仅使用公开车票示例；超时测试使用模拟 HTTP 与模拟时钟。没有新增真实百炼、高德 MCP 或 FlyAI 付费调用，不将模拟结果当作最新云端可用性证明。

## 部署与复测

本次修改了应用代码，需要创空间重新部署。部署后强制刷新或重新打开页面，避免旧页面继续使用旧事件配置；已完成的浏览器历史不应清空。

优先复测：冲突示例解析后展开置信度→检查风险→生成并应用 Plan B→展开证据区→执行本地巡检→刷新。真实行程的实时核验仍可能等待上游服务；失败应明确提示，不能把缺失证据标为成功。公网最新回归由作者部署后确认，不预先勾选为通过。
